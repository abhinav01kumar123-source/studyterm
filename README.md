# 🎓 EduPulse | Ultimate AI-Powered Study & Learning Super-App

> **100% Distraction-Free Study Ecosystem with Curated Video Lessons, Smart URL Importer, 1-Click PDF Cheatsheets, Universal File Converter, and Ambient Focus Room.**

---

## 🌟 Key Features

1. **Curriculum Topic Lessons & HD Video Lectures**:
   - Structured modules across **Mathematics, Physics, Computer Science, Chemistry, Biology, History & GK**.
   - Direct YouTube integration with **Watch on YouTube**, **Theater Mode (Full Width)**, and **Instant Seekable Video Chapters**.
   - Custom YouTube video loader — paste any educational link or Video ID to play on the fly.
   - Interactive Knowledge-Check Quizzes with explanations and celebration confetti.

2. **1-Click Topic to PDF Cheatsheets**:
   - Download complete lesson notes, formulas, and solved quiz questions formatted as clean, printable A4 PDF documents.

3. **Smart Educational URL Importer**:
   - Paste any YouTube link or web URL: automatically streams the video, extracts structured revision notes, and generates a downloadable lecture PDF.

4. **Universal Study File Converter (100% Client-Side)**:
   - **Images to PDF**: Compile homework photos/scans into a single multi-page PDF.
   - **Text/Markdown to PDF**: Format and convert notes into styled PDFs.
   - **Image Cross-Converter**: Instant conversion between PNG, JPG, and WEBP with quality slider.
   - **CSV to PDF Table & JSON**: Convert exam schedules or datasets into clean PDF tables.

5. **Zen Focus Room & Procedural Soundscape**:
   - Customizable Pomodoro Timer (25m Focus, 5m Short Break, 15m Long Break, 50m Deep Work).
   - Procedurally generated Web Audio ambient sounds (**Soft Rain, 10Hz Alpha Waves, Library Hum, Campfire**) that work 100% offline without external audio files!
   - Fullscreen Zen Mode for deep focus.

6. **Interactive 3D Study Flashcards**:
   - 3D flip animation with keyboard controls (Spacebar to flip, Arrow keys to navigate).
   - Spaced repetition self-rating system and printable PDF deck export.

7. **Smart Study Notes & Cheatsheet Creator**:
   - Rich WYSIWYG note editor with formula insertion, local auto-save, and PDF export.

## 🚀 How to Run Locally

### Option 1 (Easiest - 1 Click)
Double-click **`Run_EduPulse_App.bat`** in the main folder.

### Option 2 (Direct in Browser)
Double-click **`index.html`** to open directly in Google Chrome, Edge, or Firefox.

### Option 3 (Python Local Server)
```bash
python run_study_app.py
```
Open your browser at `http://localhost:8080`.

## 🌐 Deploy Free to GitHub Pages (Live Website)

1. Create a new GitHub repository (e.g., `edupulse-study-app`).
2. Upload all files from the `study_superapp` folder (`index.html`, `css/`, `js/`, `README.md`).
3. In your GitHub repository:
   - Go to **Settings** &rarr; **Pages**.
   - Under **Build and deployment**, select **Source: Deploy from a branch**.
   - Branch: `main` / `root`, click **Save**.
4. Within 1 minute, your live presentation link will be ready at:
   `https://<your-username>.github.io/edupulse-study-app/`
